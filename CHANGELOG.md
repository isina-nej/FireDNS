# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2025-08-28

### Added
- Complete DNS management system with IPv4 and IPv6 support
- Advanced DNS testing with multiple modes (Auto, Simultaneous, Sequential)
- Internet speed test with real-time metrics
- Custom DNS management with favorites and search
- Comprehensive notification system (Local & Push via FCM)
- Multi-language support (Persian, English, Arabic, Russian, Chinese)
- Dark/Light theme with system theme detection
- Ticket system for user support
- Auto-update functionality with forced updates
- Cross-platform support (Android, iOS, Windows, Web)
- Crash reporting and error handling
- VPN status monitoring
- Data usage tracking
- Welcome notification system
- Responsive UI with modern Material Design

### Changed
- Upgraded to Flutter 3.x
- Improved dependency management
- Enhanced error handling and user feedback
- Better performance optimization

### Fixed
- Various UI/UX improvements
- Bug fixes in DNS validation
- Improved Windows compatibility
- Fixed notification issues

## [1.0.0] - 2024-01-01

### Added
- Initial release
- Basic DNS changing functionality
- Simple UI
- Android support
